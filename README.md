# Fallout: Old Guard — загрузочный экран

Экран подключения к GMod-серверу **Fallout: Old Guard** (Helix, схема `fallout`).
Одна страница `index.html`, внешних зависимостей нет кроме шрифтов Google Fonts.

Закрывает пункт ТЗ 3 этапа №6 (дизайн) в части «загрузочный экран».

---

## ⚠️ Что нужно сделать перед заливкой

**Положить постер в `img/bg.jpg`** — ту самую картинку с девушкой и Nuka-Cola из ТЗ.

- формат JPG, ширина **1920 px и больше** (меньше — на full-HD будет мылить);
- вес держать **< 500 КБ** — картинка грузится по каналу игрока параллельно с контентом сервера;
- имя строго `bg.jpg`, либо поправить `CONFIG.background` в `index.html`.

Пока файла нет, экран не ломается: под картинкой лежит спроектированный
красный фон в той же палитре, всё остальное работает.

**Вписать реальные ссылки** Discord и VK — в `index.html`, блок `<div class="links">`
(сейчас там заглушки `https://discord.gg/` и `https://vk.com/`).

## Что на экране

| Зона | Содержимое |
|---|---|
| Правый верх | логотип (пробка Nuka-Cola, 21 зубец — как настоящая) + название **Fallout: Old Guard** |
| Левый верх | плашка режима «Hard (Serious) Roleplay» |
| Центр слева | **7 подсказок из ТЗ**, меняются по кругу каждые 7 с, с индикатором-полосками |
| Низ | прогресс загрузки, имя скачиваемого файла, ссылки, инфо о сервере |

Подсказки стоят **левее руки с бутылкой** (как просили в ТЗ). Для этого постер
сдвинут вправо на 22 %, а освободившаяся полоса слева залита тем же красным,
что и левый край постера — стыка не видно, экран читается как одна картинка.
Крутится это двумя местами в CSS: `#bg { left: 22% }` и `#seam`.

## Прогресс загрузки — настоящий

Страница слушает официальные колбэки GMod: `GameDetails`, `SetFilesTotal`,
`SetFilesNeeded`, `DownloadingFile`, `AllDownloadsComplete`, `SetStatusChanged`.
Проценты и имена файлов на живом сервере — реальные, не анимация.

Вне игры (если открыть в браузере) крутится демо-загрузка на путях контента
нашего сервера — чтобы можно было показать экран заказчику.

## Настройка

Всё, что обычно правят, — в начале `<script>`, объект `CONFIG` и массивы рядом:

```js
CONFIG.background   // путь к постеру
CONFIG.tracks       // [] — музыка выключена; ['audio/ambient1.mp3', ...] — включена
CONFIG.volume       // громкость 0..1
CONFIG.server       // имя/режим/карта/слоты до ответа сервера
CONFIG.tipInterval  // мс между подсказками
TIPS                // 7 текстов из ТЗ
PHASES              // подписи стадий подключения
```

Кнопка звука появляется только когда в `CONFIG.tracks` что-то есть.

## Публикация

1. Создать на GitHub пустой репозиторий `fallout-oldguard-loadingscreen`.
2. Из этой папки:
   ```
   git init
   git add -A
   git commit -m "Fallout: Old Guard loading screen"
   git branch -M main
   git remote add origin https://github.com/BansheeGIT/fallout-oldguard-loadingscreen.git
   git push -u origin main
   ```
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)` → Save.
   Через минуту: `https://bansheegit.github.io/fallout-oldguard-loadingscreen/`
4. В `server.cfg` сервера:
   ```
   sv_loadingurl "https://bansheegit.github.io/fallout-oldguard-loadingscreen/"
   ```
5. Перезапустить сервер.

После правок — `git add -A && git commit -m "..." && git push`, Pages пересоберётся сам.

## Локальный предпросмотр

`file://` браузеры режут, нужен http:

```
npx http-server -p 8080
```
→ `http://127.0.0.1:8080/index.html`

Можно подсунуть параметры как это делает GMod:
`?servername=Fallout: Old Guard&mapname=rp_wasteland&maxplayers=100&gamemode=fallout`

## Заметки по CEF

- Загрузочный экран GMod — это Chromium (CEF). Он **не понимает `inset`** —
  поэтому по всему файлу явные `top/right/bottom/left`. Не менять на `inset`.
- Автоплей музыки CEF может заблокировать; трек стартует по первому
  движению мыши/клику. На загрузочном экране обычно играет сразу.
- Проверено на 1920×1080 и 1366×768 (для 768p в CSS есть отдельная ветка).
